# 3DアクションRPG向け システム基盤・フレームワーク

【概要】  
プログラミングスキルの向上と設計手法の確立を目的に開発した、3DアクションRPGのシステム基盤プロジェクトです。  
ゲームの要となるアクション部分に加え、キーコンフィグ機能、音量調整システム、およびJsonUtilityを用いたJSON形式によるデータのセーブ・ロード機能といった、ゲーム運用に不可欠なシステムを一通りカバーして実装しています。

## 本プロジェクトで重視したシステム・設計
- **インターフェースによる状態管理** : プレイヤーとエネミーの挙動をカプセル化し、拡張性の高いアーキテクチャを構築。
- **データ永続化(セーブ・ロード)** : JsonUtilityを使用し、ゲームデータの保存と読み込みシステムを実装。
- **ユーザー設定の柔軟性** : プレイヤーが操作しやすいキーコンフィグ、およびJSON形式による音量調整機能。

## 主要な実装と技術的アプローチ
- **インターフェースを活用した状態管理**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  プレイヤーおよびエネミーの状態(待機、移動、追跡、攻撃など)をenumとswitch文で管理しています。  
  状態の増加に伴うコードの肥大化を防ぐため、  
  各状態の具体的なアクションはインターフェースを介して実行する設計にしました。  
  実際の動きはインターフェースを実装したクラス側にカプセル化しています。  
  これにより、メインの制御クラスがシンプルに保たれ、  
  新しい状態やエネミーのバリエーションを追加する際も、  
  既存のコードを汚さずに安全に拡張できるようになりました。  

  </details>

- **エネミーのAI・索敵システム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>
  
  指定レイヤー(プレイヤー等)のみに反応する「扇形の索敵システム」を実装しました。  
  ターゲットが戦闘範囲内(かつ攻撃範囲外)であれば自動で追跡を開始し、  
  攻撃範囲内に入ると攻撃フェーズへ移行します。  
  また、ターゲットが戦闘範囲外へ離脱すると  
  自動的に戦闘状態を解除する仕組みを構築しています。
    
  </details>

- **疎結合を意識した対話(ダイアログ)システム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  NPCとの会話やイベントシーンを制御する、汎用的な対話システムを実装しました。  
  会話データ(テキストや話者情報)をScriptableObjectで外部データ化し、  
  UI表示(ビュー)と進行管理(ロジック)を疎結合にしています。  
  UniTaskを用いたテキストの文字送りアニメーションや、  
  選択肢分岐といった拡張性の高いイベント制御を共通システムとして実現しました。

  </details>

- **フラグ管理によるクエストシステム**
  <details>
  <summary>詳細を見る（クリックで開きます）</summary>

  「受注」「条件達成」「報告完了」といった各フェーズの進行状況を  
  bool型のフラグによって管理するクエストシステムを構築しました。  
  「特定のエネミーを討伐」「特定のアイテムを収集」などといった可変する達成条件を  
  構造体として独立させることで、柔軟に組み替えられる設計にしています。
  循環参照を排除した単方向の設計により、安全な状態遷移を実現しました。

  </details>

- **ドラッグ操作に対応したインベントリシステム**
  <details>
  <summary>詳細を見る（クリックで開きます）</summary>

  アイテムパック内における、直感的なドラッグ＆ドロップによるデータ管理システムを実装しました。  
  UnityのEventSystem(IDragHandlerなど)を利用し、スロット間での「アイテムの入れ替え」や、  
  同一アイテムを重ねた際の「スタック処理」を制御しています。  
  UI上の表現と、ScriptableObjectをベースとした内部の所持データ（数量や空きスロット数）の更新を  
  正確に同期させることで、手触りの良いインベントリ操作を実現しました。

  </details>

- **ScriptableObjectを活用したデータ管理**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  アイテムデータ、ダイアログ、クエスト情報、およびAudioClip(音声データ)の管理にScriptableObjectを採用しました。  
  データをMonoBehaviourから完全に分離し、アセットとして独立して管理する構造を構築しています。  
  これにより、ゲーム実行中のデータ重複生成による処理負荷を最小限に抑え、  
  インスペクター上でのパラメータ調整や、各種マスターデータの追加・変更をコードを書き換えることなく柔軟に行えるアーキテクチャを実現しました。
  
  </details>

- **カスタムエディタによるインスペクターの拡張**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  ScriptableObjectで管理する大量のデータ(クエストやダイアログ等)の視認性と入力効率を向上させるため、  
  `EditorGUILayout.PropertyField` などを活用したインスペクターのカスタマイズ(Editor拡張)を実装しました。  
  特定の条件に応じて項目の表示・非表示を動的に切り替える仕組みなどを組み込んでいます。  
  単にゲームを動かすだけでなく、開発メンバー(プランナーやデザイナーなど)の作業効率の向上や、  
  データ入力時のストレスを軽減する「開発環境の最適化」を意識して実装しました。

  </details>

- **状態管理を用いたTPSカメラの照準ズームシステム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  遠距離武器(銃)の使用を想定した、TPSカメラの視点制御システムを実装しました。  
  エイムや非エイム状態といったズーム状態の遷移をenumとswitch文で管理し、各状態のカメラ位置の変更制御はインターフェースを介して実行する設計にしています。  
  カメラワークの切り替えロジックを各状態のクラス内部にカプセル化したことで、  
  エイムと非エイム状態に応じた滑らかな視点変更を、安全かつ拡張性の高い構造で実現しました。

  </details>

- **マルチシーン運用によるデータ管理とシーン遷移**
  <details>
  <summary>詳細を見る（クリックで開きます）</summary>

  ゲームのシーン管理には、役割に応じて以下の3つのレイヤーに分割したマルチシーン(Additive Scene Loading)を運用しました。  
  1. **コアデータシーン**: システム全体で共有する常駐マネージャー類を配置する共通シーン  
  2. **ゲームデータシーン**: プレイ時に共通して必要なプレイヤー情報やゲームUI等を配置する進行シーン  
  3. **ステージシーン**: NPC、エネミー、ステージの地形データ等のアセットを個別に配置するシーン  
  役割ごとにシーンを物理的に分離したことで、ステージ遷移時の不要なデータの破棄・再生成を最小限に抑え、  
  メモリ管理の最適化と、各データの生存期間を正確にコントロールする構造を実現しました。

  </details>

- **New Input Systemと静的クラスを組み合わせた入力管理**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  New Input Systemを採用し、各MonoBehaviourでのイベント購読と並行して、  
  入力データの管理やキーの割り当て情報を一括して保持する`InputManager`(staticクラス)を構築しました。  
  プレイヤーや各種システムは、この静的クラスを介して最新の入力設定や状態を参照する設計にしています。  
  入力を中央の静的クラスで管理・仲介させることで、クラス間の依存関係の複雑化を防ぎ、  
  他のゲームロジックに影響を与えることなく安全に行える構造を実現しました。

  </details>

- **ランタイムリバインドと重複許容ロジック**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  ゲームプレイ中におけるリバインド機能を実装しました。  
  この制御を担う中央クラスとして `RebindManager` を構築し、書き換えロジックをクラス内部にカプセル化しています。  
  システム内では、ボタンの種類や操作コンテキストに応じて「キーの重複を許容する」柔軟な割り当て構造を設計しました。  
  内部構造の複雑さを表に出すことなく、プレイヤーが矛盾のないキーコンフィグを安全に行え、  
  変更データをJSON形式でそのままセーブ・ロードできる実用的なシステムを実現しました。

  </details>

## 操作方法
本プロジェクトにおけるデフォルトのキーボード操作一覧です。  
※ゲーム内のキーコンフィグ機能から自由に変更可能です。

| アクション | キーボード（デフォルト） |
| :--- | :--- |
| **移動** | `W` `A` `S` `D` |
| **カメラ操作** | マウス移動 |
| **通常攻撃 / 射撃** | マウス左クリック |
| **エイム** | マウス右クリック |
| **リロード** | `R` |
| **インタラクト** | `F` |
| **回避** | 左`Ctrl` |
| **ジャンプ** | `Space` |
| **移動 / 走り切り替え** | 左`Shift` |
| **メニュー / ポーズ** | `Esc` |
