# 3DアクションRPG向け システム基盤・フレームワーク

【概要】  
プログラミングスキルの向上と設計手法の確立を目的に開発した、3DアクションRPGのシステム基盤プロジェクトである。  
ゲームの要となるアクション部分に加え、キーコンフィグ機能、音量調整システム、JSON形式のセーブ・ロード機能といった、ゲームに不可欠なシステムを実装している。  

## 本プロジェクトで重視したシステム・設計
- **インターフェースによる状態管理** : キャラクターやカメラの各状態の処理をカプセル化
- **データ永続化(セーブ・ロード)** : JsonUtilityを使用したゲームデータの保存と読み込みシステム
- **ユーザー設定の柔軟性** : プレイヤーが自由にカスタマイズできるキーコンフィグと音量調整機能

## 主要な実装と技術的アプローチ
- **インターフェースを活用した状態管理**

  <summary>詳細を見る(クリックで開きます)</summary>

  プレイヤーとエネミーの各種状態をenumとswitch文で管理している。  
  状態のアクションはインターフェースを介して実行する設計にした。  
  実際の動きはインターフェースを実装したクラス側にカプセル化している。  
  メインクラスがシンプルに保たれ、新しい状態やエネミーのバリエーションを追加する際も、  
  安全に拡張できるようになった。  

  </details>

- **エネミーのAI・索敵システム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>
  
  指定レイヤーのみに反応する扇形の索敵システムを実装した。  
  ターゲットが戦闘範囲内であれば追跡し、  
  攻撃範囲内に入ると攻撃フェーズへ移行する。  
  ターゲットが戦闘範囲外へ離脱すると自動的に戦闘状態を解除する仕組みにした。
    
  </details>

- **疎結合を意識した対話システム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  NPCとの会話やイベントを制御する対話システムを実装した。  
  会話テキストなどのデータをScriptableObjectで外部データ化し、  
  UI表示と進行管理を疎結合にしている。  
  UniTaskを用いたテキストの文字送りアニメーションや、  
  選択肢分岐の制御を実現した。

  </details>

- **フラグ管理によるクエストシステム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  クエストの各フェーズの進行状況をbool型のフラグによって管理するクエストシステムを構築した。  
  「エネミー討伐」「アイテム収集」といった可変の達成条件を  
  構造体として独立させることで、組み替えられる設計にしている。  

  </details>

- **ドラッグ操作に対応したインベントリシステム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  アイテムパックにおけるドラッグ&ドロップの操作システムを実装した。  
  IDragHandlerなどを用いたスロット間でのアイテムの入れ替えや、  
  スタック処理を行っている。  
  UIの表現と、スロットを制御する`InventorySlot`の内部データの更新を  
  同期させたインベントリ操作を実現した。

  </details>

- **ScriptableObjectを活用したデータ管理**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  アイテム、ダイアログ、クエスト、音声などのデータを管理するScriptableObjectを実装した。  
  データをMonoBehaviourから分離し、個別アセットとして管理する構造にしている。  
  ゲーム実行中のデータ生成による処理負荷を最小限に抑えている。

  </details>

- **カスタムエディタによるインスペクターの拡張**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  ScriptableObjectで管理しているプロパティの視認性と入力効率を向上させるため、  
  `EditorGUILayout`の表示制御などの機能を活用し、インスペクターをカスタマイズした。  
  ゲームの実装だけでなく、開発環境の最適化を意識して実装した。

  </details>

- **状態管理を用いたTPSカメラの照準ズームシステム**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  遠距離武器に合わせた、TPSカメラの視点制御システムを実装した。  
  ズーム状態の遷移をenumとswitch文で管理し、  
  各状態のカメラ制御をインターフェースを介して実行する設計にしている。

  </details>

- **マルチシーン運用によるデータ管理**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  ゲームのシーン管理には、主な役割に応じて分割したマルチシーンを運用した。  
  1. **コアデータシーン**: システム全体で共有する常駐マネージャーを配置する共通シーン  
  2. **ゲームデータシーン**: プレイ時に共通して必要なプレイヤー情報やゲームUIなどを配置する進行シーン  
  3. **ステージシーン**: NPC、エネミー、ステージの地形データ等のアセットを個別に配置するシーン  
  役割ごとにシーンを分離し、ステージ遷移時に不要なデータの破棄や再生成を最小限に抑え、  
  各データの生存期間を適切に管理する構造にした。

  </details>

- **New Input Systemと静的クラスによる入力管理**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  Input Actionの参照を管理する`InputManager`を構築した。  
  プレイヤーや各システムは、この静的クラスを介してイベント購読する設計にしている。  
  各クラスでの個別生成を防ぎ、参照先を集約した。

  </details>

- **ランタイムリバインドと重複許容ロジック**
  <details>
  <summary>詳細を見る(クリックで開きます)</summary>

  ゲームプレイ中におけるリバインド機能を制御する`RebindManager`を構築した。  
  ボタンの種類に応じて、キーの重複を許容する設計にしている。  
  変更設定はJSON形式で保存している。

  </details>

## 操作方法
本プロジェクトにおけるデフォルトのキーボード操作一覧  
※ゲーム内のキーコンフィグ機能から自由に変更可能

| アクション | キーボード（デフォルト） |
| :--- | :--- |
| **移動** | `W` `A` `S` `D` |
| **カメラ操作** | マウス移動 |
| **通常攻撃 / 射撃** | マウス左クリック |
| **エイム** | マウス右クリック |
| **リロード** | `R` |
| **インタラクト** | `F` |
| **回避** | 左`Ctrl` |
| **ジャンプ** | `Space` |
| **移動 / 走り切り替え** | 左`Shift` |
| **メニュー / ポーズ** | `Esc` |
